# Calculator

A browser calculator for basic arithmetic.

**[Try the demo](https://usmanbutt-dev.github.io/calculator/)**

## Features

- Addition, subtraction, multiplication, and division.
- Number and operator input from the page or keyboard.
- Clear and erase controls.

The JavaScript stores the current operation and updates the two display lines as input arrives. It evaluates operations in sequence.

## Run locally

Open `index.html` in a browser. It loads `script.js`, `style.css`, local assets in `resources/`, and Font Awesome icons from a third-party script. The icons require a network connection.
